# ✅ التعديلات الأربعة — جاهزة للرفع على Replit

> كل التعديلات اللي طلبتها تمت، اتفحصت بـ `node --check`، واتعمل لها اختبارات وظيفية يدوية (محاكاة) لكل نقطة. التفاصيل الكاملة في الملخص اللي بعتلك في الشات.

---

## 📦 اللي في المجلد ده

```
zangi-bot-patches/
├── اقرأني_أولاً.md          ← الملف ده
├── index.js                  ← ملف كامل معدّل (يستبدل index.js بتاعك بالكامل)
├── database.js                ← ملف كامل معدّل (يستبدل database.js بتاعك بالكامل)
└── helpers/
    └── moderation-listener.js ← ملف كامل معدّل (يستبدل helpers/moderation-listener.js بتاعك بالكامل)
```

⚠️ **مهم:** الثلاثة ملفات دول **بدائل كاملة** للملفات الأصلية بتاعتك، مش patches جزئية. يعني هتستبدل الملف القديم بالكامل بالجديد، مش تلزّق جواه.

## 🪜 خطوات الرفع على Replit (بالترتيب)

### 1) اعمل نسخة احتياطية أولاً (مهم جداً)
في Replit Shell:
```bash
cp index.js index.js.backup
cp database.js database.js.backup
cp helpers/moderation-listener.js helpers/moderation-listener.js.backup
```

### 2) ارفع الملفات الثلاثة
- ارفع `index.js` ويستبدل الموجود
- ارفع `database.js` ويستبدل الموجود
- ارفع `helpers/moderation-listener.js` ويستبدل الموجود

### 3) احذف الملف الميت
في Replit Shell:
```bash
rm -f commands/battle.js
```

### 4) شغّل فحص الـ syntax للتأكيد
```bash
node --check index.js && node --check database.js && node --check helpers/moderation-listener.js && echo "✅ كله تمام"
```

### 5) شغّل البوت وتابع الـ logs
```bash
node index.js
```

## 🧪 إزاي تتأكد إن كل تعديل شغال (اختبار يدوي في ديسكورد)

### 1️⃣ أوامر الموسيقى العربي
- جرب `/تشغيل بحث: اسم اغنية` في سيرفر وانت داخل في قناة صوتية → المفروض تشتغل الأغنية
- جرب `/تخطي`, `/توقف-مؤقت`, `/استئناف`, `/قائمة-تشغيل`, `/إيقاف` → كل واحد المفروض يرد بنفس سلوك نسخته الإنجليزية
- جرب `/تشغيل` من الـ **DM** (الخاص مع البوت) وانت داخل سيرفر فيه قناة صوتية → المفروض البوت يحدد الـ voice channel بتاعك صح بدون أي مشكلة (ده بيستخدم نفس الـ DM proxy المستخدم مع `/play`)

### 2️⃣ Anti-Raid
- ده بيتفعّل تلقائيًا، لكن مايعملش حاجة فعلية (قفل قنوات) إلا لو عندك `ADMIN_CHANNEL_ID` و `OWNER_ID` متظبطين في الـ Secrets/.env
- لو عايز تتأكد إنه شغال: ادخل بحسابين/تلاتة تجريبيين بسرعة (أكتر من `ANTI_RAID_THRESHOLD`، افتراضيًا 10 خلال 30 ثانية) وشوف هل البوت قفل القنوات وبعت تنبيه في القناة الإدارية
- ⚠️ لو `ADMIN_CHANNEL_ID` مش متظبط، البوت **مش هيقفل حاجة خالص** ويكتب تحذير في الـ console بس — ده تصرف مقصود (أمان) عشان ميقفلش قنوات بدون ما يقدر يبلغك

### 3️⃣ حذف battle.js
- تأكد إن `/مساعدة` أو قائمة الأوامر مش فيها أي أمر اسمه `battle` أو حاجة تشبهها
- تأكد إن لعبة حجر-ورقة-مقص (RPS) لسه شغالة عادي عبر الأمر الموجود فعلاً في `games.js`

### 4️⃣ claimAiMessage في الذاكرة
- ابعت رسالة عادية للبوت (مش أمر slash) عشان يردّ بالـ AI → المفروض يرد عادي
- ابعت رسالتين سريعة جدًا فوق بعض → المفروض كل واحدة تتعامل بشكل طبيعي، مفيش تجميد أو تأخير ملحوظ (لأن مفيش I/O على الديسك دلوقتي)
- لو معاك صلاحية وصول للسيرفر، شوف `server_database.json` بعد فترة → هتلاقي مفتاح جديد اسمه `aiMessageClaims` (بدل `aiClaims` القديم)

## ⚠️ ملاحظة مهمة جداً بخصوص الـ multi-instance

التعديل بتاع `claimAiMessage` (نقطة 4) بيحل مشكلة **الأداء والـ blocking I/O** جوه نفس نسخة البوت الواحدة، باستخدام Map في الذاكرة بدل قراءة/كتابة الملف بالكامل في كل رسالة.

**لكنه مايحميش من تكرار الردود لو شغّلت نسختين من البوت في نفس الوقت** (مثلاً نسخة على جهازك + نسخة على Replit، أو نسختين Replit)، لأن الـ Map دلوقتي في الذاكرة بس مش على الديسك المشترك.

لو المشكلة الأصلية بتاعتك (الرسايل المكررة 2-3 مرات) كانت سببها **multi-instance** فعليًا (يعني نسختين شغالين فعلاً في نفس الوقت)، فده محتاج نظام تنسيق إضافي عبر الديسك (single-instance lock + claim store عبر الـ disk) — وده شيء تاني تمامًا عن التعديلات الأربعة اللي طلبتها هنا. لو عايز، قولي وأنا أطبّقه كخطوة منفصلة.

## 🔒 ملاحظة أمنية (مش جزء من التعديلات، بس لازم تعرفها)

لاحظت إن في ملفات `token.json` و `credentials.json` و `cookies.txt` موجودة في المشروع وفيها بيانات Google حقيقية (access token, refresh token, client secret). أنا مالمستهمش ولا رفعتهم في الحزمة دي. لو دول موجودين في مكان تاني مش عام، الوضع مقبول، بس لو في أي وقت حسيت إنهم اتكشفوا أو محتاج تجدد الـ tokens، تقدر تروح على [Google Account Permissions](https://myaccount.google.com/permissions) وتلغي صلاحية التطبيق وتعمل OAuth جديد.
