## 🔍 المشكلة اللي اكتشفتاها

البوت كان بيدي الخطأ ده لما حد بيبعت رابط Spotify:
```
DisTubeError: [NO_EXTRACTOR_PLUGIN]: There is no extractor plugin in the 
DisTubeOptions.plugins, please add one for searching songs
```

**السبب الحقيقي:**
> الـ `@distube/spotify` v2.0.2 مش بيشغّل الصوت من Spotify مباشرة. هو بياخد **اسم الأغنية من Spotify URL** وبيعمل **بحث في YouTube** عن نفس الأغنية عشان يشغّلها. فلازم الـ `YtDlpPlugin` يكون موجود كـ **backend** جنبه.

**الحل:**
- ✅ رجعنا `YtDlpPlugin` للـ plugins array (بصيغة silent، مش بيظهر لليوزر)
- ✅ لكن **النظام كله بياخد URLs وطلبات من Spotify بس** — مفيش YouTube URLs مقبولة
- ✅ لو حد بعت رابط YouTube/SoundCloud، البوت بيرفض فوراً برسالة واضحة
- ✅ كل البحث بيبقى من Spotify (`spsearch:` prefix)

## 🧠 فهم النظام الجديد (مهم)

**قبل:**
```
user input → YouTube (yt-dlp) → SoundCloud (fallback)
```

**دلوقتي:**
```
user input → [Spotify URL?] → SpotifyPlugin → يجيب اسم الأغنية
         ↓                              ↓
    [نص بحث؟]                    YtDlpPlugin (backend)
         ↓                              ↓
    spsearch: query           → YouTube (بحث عن نفس الأغنية)
         ↓                              ↓
    [YouTube/SoundCloud URL؟] → ❌ مرفوض!
         ↓
    يشغّل الصوت
```

**الخلاصة:** البوت **من بره** Spotify-Only (مستخدم بيشوف Spotify بس)، **من جوه** بيستخدم YouTube كـ audio source. ده مش cheating — ده الطريقة الوحيدة لأن Spotify مفيش direct audio streaming API مجاني.
