# 🎯 أمر Replit Agent — تطبيق التعديلات على بوت زنجي

## ⚠️ مهم جداً قبل ما تبدأ

أنا عملت كل التعديلات في ملف مضغوط نظيف اسمه **`discord-bot-cleaned.zip`** (511KB بدل 51MB الأصلي). 

**الخطوة الأولى:** ارفع الـ zip ده فوق الـ Replit الحالي (أو استخدمه لاستبدال الملفات في المشروع). بعد رفعه وفك ضغطه، اتأكد إن البنية في Replit مطابقة للملفات في الـ zip.

بعدها نفّذ الخطوات التالية بالترتيب:

## 📋 الخطوة 1: التحقق من البنية الحالية

```bash
cd discord-bot-main

# 1.1. تحقق من وجود الملفات المتوقعة
echo "=== البنية ==="
ls -la
echo ""
ls -la commands/
echo ""
ls -la helpers/

# 1.2. تحقق إن الملفات المتوقعة موجودة
required_files=(
  "index.js"
  "commands/music.js"
  "helpers/music-card.js"
  "package.json"
)
for f in "${required_files[@]}"; do
  if [ -f "$f" ]; then echo "✅ $f"; else echo "❌ $f مفقود!"; fi
done
```

لو ملف `discord-bot-cleaned.zip` مش مرفوع، قوله: "ارفع الملف `discord-bot-cleaned.zip` للمشروع وفك ضغطه فوق الـ Replit".

## 📦 الخطوة 2: تنظيف `package.json` وتثبيت الحزم

```bash
cd discord-bot-main

# 2.1. احذف node_modules القديمة و package-lock.json عشان نضمن تثبيت نظيف
rm -rf node_modules
rm -f package-lock.json

# 2.2. تحقق إن package.json شامل الحزم الصحيحة
cat package.json

# 2.3. ثبّت الحزم
npm install

# 2.4. لو حصلت أخطاء، جرب:
# npm install --legacy-peer-deps
```

## 🔍 الخطوة 3: التحقق من Syntax

```bash
cd discord-bot-main

# فحص كل ملفات JS
for f in commands/*.js helpers/*.js index.js; do
  if node --check "$f" 2>&1 | grep -q "error"; then

```

لو فيه أي خطأ، **لا تستمر** — أصلحه الأول.

## 🎵 الخطوة 4: التحقق من نظام الموسيقى الجديد (Spotify-Only)

```bash
cd discord-bot-main

echo "=== 1. تحقق إن plugins بقت SpotifyPlugin بس ==="
grep -A 3 "plugins:" commands/music.js

echo ""
echo "=== 2. تحقق إن detectSourceType مفيهاش YouTube/SoundCloud ==="
sed -n '/^function detectSourceType/,/^}/p' commands/music.js

echo ""
echo "=== 3. تحقق إن البحث النصي بيستخدم spsearch: ==="
grep -n "spsearch:" commands/music.js

echo ""
echo "=== 4. تحقق إن مفيش YouTube/SoundCloud في الكود النشط (عدا whitelist) ==="
grep -rn "youtube\.com\|soundcloud\|YtDlpPlugin\|SoundCloudPlugin\|yt-dlp" --include="*.js" . | grep -v node_modules
```

**الناتج المتوقع:**
- السطر الأول يطبع `[ new SpotifyPlugin() ]` بس
- السطر التاني فيه بس روابط Spotify
- السطر الثالث فيه `spsearch:` query
- السطر الرابع مفيهوش حاجة (عدا `youtube.com` في whitelist الـ moderation)

## 🧪 الخطوة 5: تشغيل تجريبي

```bash
cd discord-bot-main

# ⚠️ متشغّلش البوت لحد ما تكون متأكد إن الـ DISCORD_TOKEN موجود في الـ Secrets

if [ -z "$DISCORD_TOKEN" ]; then
  echo "⚠️ DISCORD_TOKEN مش موجود في الـ Secrets!"
else
  echo "✅ DISCORD_TOKEN موجود"
fi

if [ -z "$GOOGLE_API_KEY" ]; then
  echo "⚠️ GOOGLE_API_KEY مش موجود"
else
  echo "✅ GOOGLE_API_KEY موجود"
fi
```

**لو الـ Secrets موجودة:**
```bash
npm start
```

راقب الـ console. المفروض تشوف:
- `✅ [Replit] Logged in as زنجي#...`
- `✅ [Music] DisTube initialized with Spotify plugin`
- (ومفيش أخطاء في الـ startup)

**لو مفيش Secrets:**
- متشغّلش البوت.
- اطلب من المستخدم إنه يضع الـ Secrets في Replit (من Tools → Secrets).

## 🎯 الخطوة 7: اختبار عملي في Discord

بعد ما البوت يشتغل، اختبر الأوامر دي في سيرفر Discord:

1. **بحث نصي:**
   ```
   /شغل اغنية:humood alkhudher alons
   ```
   المفروض يدور في Spotify ويشغّل.

2. **رابط أغنية:**
   ```
   /شغل اغنية:https://open.spotify.com/track/...
   ```
   المفروض يشغّل على طول.

3. **بلاي ليست:**
   ```
   /شغل اغنية:https://open.spotify.com/playlist/...
   ```
   المفروض يحمّل البلاي ليست ويبدأ التشغيل.

4. **رابط YouTube (لازم يفشل برسالة واضحة):**
   ```
   /شغل اغنية:https://youtube.com/watch?v=...
   ```
   المفروض يقول "مش لاقي الأغنية دي على Spotify".

## ❌ لو حصلت مشكلة

1. **خطأ في `npm install`:** جرب `npm install --legacy-peer-deps`
2. **`Cannot find module '@distube/spotify'`:** تأكد إن `package.json` فيه `@distube/spotify` وإن `npm install` اشتغلت
3. **Spotify مش بيلاقي نتيجة:** جرب اسم أغنية مختلف. لو المشكلة مستمرة، اعمل restart للـ Repl.
4. **البوت مش بيبدأ:** شوف الـ console logs. لو فيه `TypeError` أو `Cannot find module`، ابعت الـ error كامل.
5. **مشكلة في `/play` command:** تأكد إن `DISCORD_TOKEN` صحيح وإن البوت في voice channel مع المستخدم.

> **لو حصلت أي مشكلة:** **لا تحاول إصلاحها بنفسك** — ابعتلي التفاصيل وأنا هساعدك.
